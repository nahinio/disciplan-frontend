# DisciPlan Frontend

React + TanStack Start + Vite + Tailwind CSS.

## Local development

```bash
npm install
cp .env.example .env
npm run dev
```

Set `VITE_API_BASE_URL` in `.env` to your local backend (e.g. `http://localhost:8000/api/v1`).
